# Math — интерактивные уроки математики

Каждая тема — отдельная папка с двумя файлами:

```
<тема>/index.html      — урок: один файл HTML + CSS + JS, без зависимостей и без сборки
<тема>/<тема>_demo.py  — то же на Python: tkinter + стандартная библиотека, без pip
```

Уже есть: `fractions/` (дроби), `powers/` (степени), `roots/` (корни).
Новый урок начинайте с копии самого свежего (`roots/index.html`): там самый полный набор помощников.

Язык всего контента — русский. Аудитория — школьники, поэтому коротко, конкретно и с бытовыми примерами.

## Структура урока (index.html)

`header` (h1 «<Тема> в движении», подзаголовок, `nav` со ссылками на разделы), затем 7 разделов `<section id="sN">`:

1. **Что такое …** — определение через картинку и ползунки.
2–5. **Механика темы** — обратное действие, свойства, алгоритмы, особые случаи (0, отрицательные числа, частые ошибки). На каждый раздел — одна визуальная идея.
6. **Зачем нужны …** — обязательный раздел:
   - вводный абзац: в какой ситуации нужно это действие;
   - сетка `.uses` из 4–6 карточек `.use`: иконка-эмодзи, название, где применяется, какие задачи решает, `<em>Признак:</em>` — как узнать такую задачу по условию;
   - «Попробуйте сами»: 4 вкладки (`.tabs` и `[data-use]`), объект `USES = { key: { controls, render() } }` и функция `buildUse()`. Каждый пример — реальная задача с ползунками, анимацией, формулой, чипами-выводами и абзацем `.answer` с главной мыслью.
7. **Проверь себя** — случайные задания: 5–7 типов, включая текстовые задачи из раздела 6. Подсказка при ошибке (`q.hint`), счёт, тряска `.shake`, после верного ответа через ~1,3 с новое задание. Где возможно, засчитывать равносильные ответы (у дробей — эквивалентные).

Раздел строится так: `h2` с `<small>` (подзаголовок), `p.lead` (одна фраза — суть), затем `.grid` из двух колонок: слева `.ctl` (большая формула `.big`, ползунки `label.r`, кнопки `.btns`), справа рисунок (SVG) и чипы `.info`.

## Дизайн и код

- Цвета только через токены `:root`: `--bg --card --ink --muted --line --empty --a --b --c --gold`. Тёмная тема — через `@media (prefers-color-scheme: dark)`. В SVG задавать цвет через `style.fill = 'var(--a)'`, а не через атрибут `fill`.
- Анимации — CSS-классы: `.pop` (появление с пружинкой; задержка через `animation-delay`, ограничивать `Math.min(i*k, ~1500)`), `.fade`, `.shake`, `.draw` (рисование линии: нужен `pathLength="1"`), `.grow` (столбик растёт снизу), `.move` или `.slide` (плавный `transform`). Чтобы маркер двигался плавно, обновлять `style.transform` у существующего элемента, а не пересоздавать SVG.
- Помощники (копировать из урока): `$`, `el(tag, attrs, parent)`, `style()`, `bindRange(id, onChange)`, `num` / `fmt` (формат ru-RU, дробная часть через запятую), `slider()`, `chipsHTML()`, `restart(node, cls)`, `rnd` / `pick`. Для темы: `frac()` (дроби), `pw()` (степени), `rt()` (корни).
- Большие числа — через `BigInt` (пример: пароли в `powers`).
- В обработчиках `input` вызывать `() => u.render()`, а не `u.render`: иначе внутри `render` `this` указывает на элемент input.
- Макет должен работать на ширине телефона (`@media (max-width: 720px)` — одна колонка).

## Python-версия (<тема>_demo.py)

- `tkinter`, палитра `COLOR_A/B/C`, `BG = "#f6f3ec"`, шрифт `Segoe UI`.
- Анимация через `after()`: рисовать по одной фигуре или кадру и отменять предыдущий `_job` через `after_cancel`.
- Главное окно `App(tk.Tk)` — основные понятия. Кнопка «Зачем нужны …? →» открывает `UsesWindow(tk.Toplevel)` с текстом применений и 3 задачами из жизни.
- Для точных вычислений — `fractions.Fraction`, `math.isqrt` и т. п.

## Проверка перед сдачей (Windows, PowerShell)

```powershell
python -m py_compile <тема>\<тема>_demo.py
$html = Get-Content <тема>\index.html -Raw -Encoding utf8
$js = [regex]::Match($html, '(?s)<script>(.*)</script>').Groups[1].Value
Set-Content "$env:TEMP\check.js" $js -Encoding utf8; node --check "$env:TEMP\check.js"
Start-Process <тема>\index.html
```

Это проверка только синтаксиса. Если анимации и кнопки не были просмотрены в браузере, нужно прямо сказать об этом пользователю.
