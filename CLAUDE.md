# Math — интерактивные уроки математики

Главная страница курса — `index.html` (+ `style.css`, `script.js`) в корне. Все уроки лежат в папке `lessons/`,
каждая тема — отдельная папка из трёх файлов, без зависимостей и без сборки:

```
lessons/<тема>/index.html  — разметка урока
lessons/<тема>/style.css   — стили
lessons/<тема>/script.js   — логика (подключается в конце body: <script src="script.js">)
```

Python-версии уроков не делаем (пользователь считает их лишними).

Главная — карта всех 7 блоков. Темы хранятся в массиве `COURSE` в корневом `script.js`; у готового урока есть `href`, у остальных — нет (показываются как «скоро»).

Уже есть (в `lessons/`): `fractions/` (дроби), `powers/` (степени), `roots/` (корни), `percents/` (проценты), `algebra/` (переменные, выражения, уравнения), `functions/` (линейная, квадратичная, экспонента, логарифм), `graphs/` (координаты, чтение графиков, сдвиги, данные → график), `derivative/` (производная, экстремумы, градиентный спуск), `vectors/` (векторы: сложение, умножение на число, разность, признаки).
Новый урок начинайте с копии самого свежего (`lessons/vectors/`, все три файла; там же `plane()` и `arrow()` — стрелки-векторы; `line()` для касательных — в `lessons/derivative/`; `lsq()` — метод наименьших квадратов — в `lessons/graphs/`): там самый полный набор помощников.

Язык всего контента — русский. Аудитория — школьники, поэтому коротко, конкретно и с бытовыми примерами.

## Структура урока (index.html)

`header` (ссылка `a.home` «← Все уроки» на `../../index.html`, h1 «<Тема> в движении», подзаголовок, `nav` со ссылками на разделы), затем 7 разделов `<section id="sN">`:

1. **Что такое …** — определение через картинку и ползунки.
2–5. **Механика темы** — обратное действие, свойства, алгоритмы, особые случаи (0, отрицательные числа, частые ошибки). На каждый раздел — одна визуальная идея.
6. **Зачем нужны …** — обязательный раздел:
   - вводный абзац: в какой ситуации нужно это действие;
   - сетка `.uses` из 4–6 карточек `.use`: иконка-эмодзи, название, где применяется, какие задачи решает, `<em>Признак:</em>` — как узнать такую задачу по условию;
   - «Попробуйте сами»: 4 вкладки (`.tabs` и `[data-use]`), объект `USES = { key: { controls, render() } }` и функция `buildUse()`. Каждый пример — реальная задача с ползунками, анимацией, формулой, чипами-выводами и абзацем `.answer` с главной мыслью.
7. **Проверь себя** — случайные задания: 5–7 типов, включая текстовые задачи из раздела 6. Подсказка при ошибке (`q.hint`), счёт, тряска `.shake`, после верного ответа через ~1,3 с новое задание. Где возможно, засчитывать равносильные ответы (у дробей — эквивалентные).

Раздел строится так: `h2` с `<small>` (подзаголовок), `p.lead` (одна фраза — суть), затем `.grid` из двух колонок: слева `.ctl` (большая формула `.big`, ползунки `label.r`, кнопки `.btns`), справа рисунок (SVG) и чипы `.info`.

## Дизайн и код

- Цвета только через токены `:root`: `--bg --card --ink --muted --line --empty --a --b --c --gold`. Тёмная тема — через `@media (prefers-color-scheme: dark)`. В SVG задавать цвет через `style.fill = 'var(--a)'`, а не через атрибут `fill`.
- Анимации — CSS-классы: `.pop` (появление с пружинкой; задержка через `animation-delay`, ограничивать `Math.min(i*k, ~1500)`), `.fade`, `.shake`, `.draw` (рисование линии: нужен `pathLength="1"`), `.grow` (столбик растёт снизу), `.move` или `.slide` (плавный `transform`). Чтобы маркер двигался плавно, обновлять `style.transform` у существующего элемента, а не пересоздавать SVG.
- Помощники (копировать из урока): `$`, `el(tag, attrs, parent)`, `style()`, `bindRange(id, onChange)`, `num` / `fmt` (формат ru-RU, дробная часть через запятую), `slider()`, `chipsHTML()`, `restart(node, cls)`, `rnd` / `pick`. Для темы: `frac()` (дроби), `pw()` (степени), `rt()` (корни).
- Большие числа — через `BigInt` (пример: пароли в `powers`).
- В обработчиках `input` вызывать `() => u.render()`, а не `u.render`: иначе внутри `render` `this` указывает на элемент input.
- Не давайте элементам `id` вида `s1`…`s7`: это `id` разделов, и `$('s5')` вернёт `<section>` вместо ползунка (на странице появится «не число»).
- Макет должен работать на ширине телефона (`@media (max-width: 720px)` — одна колонка).

## Проверка перед сдачей (Windows, PowerShell)

```powershell
node --check lessons\<тема>\script.js
Start-Process lessons\<тема>\index.html
```

Снимок страницы без окна (видно, что все разделы отрисовались и JS не упал при загрузке):

```powershell
& "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --virtual-time-budget=4000 --window-size=1000,6200 --screenshot="<scratchpad>\shot.png" "file:///C:/dev/Math/lessons/<тема>/index.html"
```

Это не проверка кликов и ползунков. Не прячьте основное содержимое за анимацией появления (`opacity: 0` до старта): в браузере без окна такие анимации на главной так и не стартовали. Если анимации и кнопки не были просмотрены в браузере, нужно прямо сказать об этом пользователю.

## После урока

- Добавить тему в список «Уже есть» в начале этого файла.
- В корневом `script.js` прописать у темы в `COURSE` `href: 'lessons/<тема>/index.html'`.
- Пользователь просит уроки в формате «покажи … с анимацией и интерактивными примерами на html css js». Ответ — на русском, кратко по разделам.
